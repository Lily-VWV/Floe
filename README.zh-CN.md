# Floe · 浮光

[English](README.md) | 简体中文

Windows 桌面托盘工具。在指定时刻显示半透明数字，也可让时钟常驻桌面，到点再闪烁提醒。

默认使用简体中文界面，名称为 **浮光**。设置顶部可切换 **简体中文 / English**，点击 保存／Save 后记住选择；英文界面名称为“Floe”。关闭设置而未保存时，恢复已保存的语言。新配置、没有语言字段的旧配置及无效语言值使用中文；已保存的语言选择、时钟和提醒选项继续保留。

## 使用

要求 Windows x64。在 [v0.7.1 发布页](https://github.com/Lily-VWV/Floe/releases/tag/v0.7.1) 下载以下任一 ZIP，解压后运行文件夹中的 `TimeOnScreen.exe`：

| 下载 | 运行要求 |
| --- | --- |
| [普通版压缩包](https://github.com/Lily-VWV/Floe/releases/download/v0.7.1/Floe-v0.7.1-win-x64.zip) | 需要 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)，保留全部解压文件 |
| [自带运行环境版压缩包](https://github.com/Lily-VWV/Floe/releases/download/v0.7.1/Floe-v0.7.1-win-x64-standalone.zip) | 无需另外安装 .NET，解压即用 |

两个包均附中英文说明、MIT 许可证及所包含 .NET 组件的许可声明。发布页的 `SHA256SUMS.txt` 提供校验值。自动生成的 **Source code** 下载项是源码，须编译后才能运行。

源码构建方式见下文。普通版输出至 `artifacts/app/`，独立运行版输出至 `artifacts/standalone/`。独立版的可执行文件包含运行组件，首次运行会自动解压；再次分发时请保留许可文件和声明。发布程序不纳入源码版本管理。

1. 点击 **预览**，用当前表单设置播放效果；预览不会保存修改。
2. 调整显示、提醒和外观，再点击 **保存**。显示器、位置、偏移与开机启动在 **更多设置** 中。
3. 关闭设置窗口后继续在托盘运行。双击托盘图标重新打开设置；右键可预览、暂停或退出。

默认每个整点显示 24 小时制时间（例如 `12:00:01`）：字号 160、白色、80% 不透明度、中央偏上、柔和闪烁 5 秒。数字每秒跟随系统时间更新，每个新秒变亮，半秒时变暗，再在下一秒变亮。显示窗口不抢输入焦点，鼠标点击穿透。

- 固定周期：整点、半小时或不使用固定周期。
- 每天指定时间：例如 `01:29, 13:29`，每天在凌晨 1 点 29 分和下午 1 点 29 分提醒。始终按 24 小时制填写，与数字显示格式无关。
- 每小时指定分钟：例如 `45`，每小时的 45 分提醒；`15, 45` 表示每小时的 15 分和 45 分都提醒。范围 0～59。
- 两种自定义规则均可填写多个，用中文或英文逗号分隔。保存时排序、去重；留空表示不设置该类提醒。
- 自定义规则可与固定周期叠加，时间重合时只提醒一次。**只需要每小时 45 分提醒**时，将固定周期选为“不使用固定周期”，每日时间留空，每小时分钟填写 `45`，再保存。
- **常驻显示**：勾选并保存后，时钟持续显示并更新数字，平时不闪烁。到提醒时间按所选方式闪烁，持续时间结束后恢复常驻。关闭设置窗口后仍然显示；字号、颜色、透明度、屏幕位置与提醒共用。取消勾选并保存后，恢复只在提醒时显示。
- **只显示时钟、不设提醒**：开启常驻显示，固定周期设为“不使用固定周期”，两个自定义输入留空，再保存。
- 提醒闪烁方式：柔和闪烁、明灭闪烁、不闪烁。提醒持续时间只控制提醒或预览的秒数，不限制常驻时钟。
- 外观：点击颜色旁的小色块打开选色盘，拖动选择颜色和明暗，下方彩色条调整色相；也可填写 `#RRGGBB`。点选色盘外或按 Esc 收起。颜色、不透明度分别调节，改动点击保存后生效。
- 字号：拖动滑动条调节 32～400，右侧显示数值，方向键按 1 微调。点击底部“预览”查看实际桌面效果。
- 默认显示秒数；取消“显示秒数”可恢复小时和分钟。12 小时制支持 `3:00:01 PM`。
- 默认“每秒同步”，与系统秒数变化同步。取消后可以自定义闪烁周期，秒数仍每秒更新。“不闪烁”表示本次提醒期间只更新数字；常驻时钟始终不闪烁。
- 屏幕：主显示器、鼠标所在显示器、指定显示器；指定屏幕断开后回到主屏。
- 位置：中央偏上／中／下、四角；可以微调偏移。偏移按 Windows 逻辑像素解释，正值向右或向下。
- 可限制提醒时段，支持跨午夜；结束时间不包含在时段内。该限制对所有固定周期及自定义提醒都生效，不影响常驻时钟；有提醒规则时，时段必须包含至少一个提醒时刻。
- 开机启动默认关闭。勾选并保存后，写入当前用户启动项，不需要管理员权限。设置启动项后不要移动应用文件夹；移动后请重新关闭再开启此选项。
- 暂停只作用于本次运行，重启恢复提醒。暂停提醒后，常驻时钟继续显示，预览仍可使用。

启动或保存设置时等待下个提醒时刻；开启常驻显示时，时钟立即出现。恢复休眠时不连续补报，只有距当前分钟的提醒时刻不超过 5 秒时才报当前时间。所有提醒都在对应分钟的第 0 秒触发，悬浮数字显示实时秒数。锁屏和休眠时隐藏时钟；解锁或恢复后重新常驻，锁屏期间跳过提醒。系统时间或时区改变时重新计算，近期相同本地时间不会重复报时。

配置：`%LocalAppData%/TimeOnScreen/settings.json`。损坏配置使用默认值，原文件保留至再次保存。异常日志：同目录 `errors.log`。应用不使用网络服务、不收集使用数据。

普通桌面窗口是目标场景。独占全屏游戏、安全桌面和其他置顶窗口可能遮挡报时，第一版不保证覆盖这些界面。

## 开发与验证

要求 Windows x64 和 .NET 10 SDK，不需要外部 NuGet 库。

```powershell
./build.ps1                  # 编译、逻辑测试、依赖本机运行环境的发布包
./build.ps1 -SelfContained   # 编译、逻辑测试、自带运行环境的发布包
```

桌面集成检查（会打开测试窗口约 18 秒，短暂移动鼠标检查色盘拖动后恢复原位，不更改用户设置和启动项）：

```powershell
./artifacts/app/TimeOnScreen.exe --verify ./artifacts/verification
# 或使用 PowerShell 7：
pwsh -NoProfile -File ./verify.ps1
pwsh -NoProfile -File ./verify.ps1 -Package standalone
pwsh -NoProfile -File ./verify.ps1 -Package build
```

检查设置按钮、保存与输入校验、色盘选色与鼠标拖动、字号滑动条及预览、暂停与恢复、透明像素、数字不透明度、置顶、不激活、鼠标穿透、位置、闪烁变化、定时隐藏、重复预览、常驻时钟更新、提醒后恢复常驻、锁屏和休眠状态切换；输出 `report.json`、设置界面、色盘及数字 PNG。状态切换使用隔离测试，不会实际锁屏或休眠。逻辑测试涵盖定时误差、休眠、午夜、暂停、跨午夜时段、时钟回退、多屏负坐标和配置恢复。

## 结构

- `src/TimeOnScreen.Core`：设置、定时调度、屏幕位置和配置存储。
- `src/TimeOnScreen`：WPF 设置界面、透明窗口、托盘、系统事件和开机启动。
- `tests/TimeOnScreen.Tests`：无外部依赖的逻辑回归检查。

窗口实现参考：[WPF 窗口](https://learn.microsoft.com/zh-cn/dotnet/desktop/wpf/windows/)、[透明分层窗口](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。
